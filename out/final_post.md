Large-load financial security before study inclusion, under 16 TAC §25.194 adopted September 18th, 2026.
Large loads in ERCOT must post $50,000 per MW of financial security before study inclusion.

The mechanism is a rule that conditions a large load's place in an ERCOT interconnection study on posting financial security first. The commission's order was filed September 18th, 2026 under Project No. 58481, and it implements PURA §37.0561 as enacted by SB 6 in the 89th Regular Legislative Session.

The layer chain, from the primary record.

- Statutory mandate. The Texas Legislature enacted PURA §37.0561 through SB 6, which directs standards for large load interconnection.
- Commission rule adoption. The Public Utility Commission of Texas adopted new 16 TAC §25.194 in Project No. 58481, changed from the March 27, 2026 Texas Register proposal.
- Financial security gate. The Public Utility Commission of Texas requires a large load customer to post financial security of $50,000 per MW before it is included in an ERCOT interconnection study.
- ERCOT study inclusion. ERCOT places an eligible large load into its interconnection study once the prerequisites are met, and the order discusses the batch zero study.
- Security return on energization. The interconnecting DSP or TSP returns 20% of financial security when the large load customer energizes, and the remainder in 20% increments as milestones are met.

The chokepoint is the Public Utility Commission of Texas. The binary decision is whether a large load customer must post financial security before study inclusion, at $50,000 per MW, before it can take a place in the study.

The structural read is narrow. The rule puts the posting condition ahead of the study, and the order records how the security comes back. The order also refers to a June 18th, 2026 commission action on the batch zero interconnection study, so the posting rule sits beside an existing ERCOT queue process rather than replacing it. The measurable items are the per-megawatt amount and the return steps in the order, which apply to ERCOT's grid and not to the whole state.

The next check is the republication of 16 TAC §25.194 in the Texas Register, which the order says will follow.
